# Skill: ip_protect_and_registration_playbook

## R（原文锚点）
- CNIPA 明确商标申请、缴费、续展与代理方式。
- 初创问题通常集中在“命名、源码、版权、员工/外包成果归属”。

## I（重构）
把“要不要、先做什么、谁签、什么时候提交”转化为三段防线：资产识别、权利落地、冲突预防。

## A1（现有案例）
- 常见误区：Logo 完成后才想到商标，市场传播已先行。
- 外包代码未在协议中约定 IP 归属，后续融资时被追问。

## A2（触发场景）
- 触发：`有了新品牌/新名称`
- 触发：`有AI生成内容和代码`
- 触发：`准备对外投资和合作`

## E（执行步骤）
1. 识别资产：商标/源码/文档/模型输出/训练数据。
2. 按法域输出最小落地顺序：
   - CN：商标申请书、身份与主体材料、费用与优先权
   - US：商标申请渠道与权属风险核对
   - 合作：员工与供应商 IP 归属条款
3. 输出 30 天防火墙：命名冻结、授权矩阵、版本清单。
4. 输出 90 天补强：续展、监测、异议预案。

## B（边界）
- 不提供具体检索结果和诉讼策略。
- 商标审查结果的否定性结论需交由代理机构/律师。
- 不能替代正式版权法务审查意见。
