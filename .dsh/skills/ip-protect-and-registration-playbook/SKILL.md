# IP 与商标保护

按“资产识别 → 权利落地 → 冲突预防”组织回答。盘点商标、源码、文档、模型输出、训练数据和员工/供应商成果；按法域说明最小行动顺序，例如商标申请材料/权属核验以及员工、承包商、供应商的 IP 归属条款。

给出 30 天动作（命名冻结、授权矩阵、版本清单）与 90 天补强（监测、续展、异议预案）。不要声称完成商标检索、预判审查结果或制定诉讼策略；确定性结论交代理机构或律师。原始技能草案见 `references/source.md`。
