# 成立法务体检

先确认法域（CN / US / EU）、公司阶段（预营运、新营运、已有营收、已有用户）与业务是否处理个人信息。按下列层次输出，不把清单表述为正式法律意见。

1. **A 类：必须先完成**：法定备案/主体信息、税务识别、劳动关系底层文件、财税账户。
2. **B 类：高频且应尽快完成**：雇佣合同模板、隐私通知、商标查询。
3. **C 类：可并行完成**：服务协议、合作协议、股权协议草案。
4. 按 7 / 30 / 90 天列出负责人、前置条件和未决事项。

不得给出具体税额或注册地择址结论。出现用工争议、隐私事件或融资交易时，明确要求当地律师复核。输出前将使用的法源或本地知识库条目列为可核验依据；原始技能草案见 `references/source.md`。
