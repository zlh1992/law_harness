# 用工关系与合同风控

收集岗位的薪酬方式、考勤与管理控制、工具归属、客户交付责任、排他性、持续性、专业独立性及是否属于核心岗位。不要只按合同标题判断。

按“身份判定依据 → A 高风险 / B 边界明确 / C 低风险 → 立即行动 → 律师复核项”输出。立即行动可包括合同补签、社保与工资记录核对、承包主体资格/工作说明核对；律师复核项应包括税务、工伤和派遣/外包责任。

不裁判个案结果、不估计胜诉概率、不确定具体责任比例；必须提示适用法域与事实不足。原始锚点及边界见 `references/source.md`。
