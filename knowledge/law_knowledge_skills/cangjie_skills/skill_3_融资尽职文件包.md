# Skill: seed_due_diligence_pack

## R（原文锚点）
- Cooley VC DD 清单包含公司治理、股权、财务、知识产权、劳动与监管文档。
- SEC 和小企业资本市场资料强调信息披露与治理文件完整性。

## I（重构）
将“融资时被反复追问的文件”转成分轮次、分优先级的文件包与缺口修复路径。

## A1（现有案例）
- 种子轮最常见缺口：cap table 缺更新、委托/竞业条款不一致、劳动合同未归档。
- 投资前常见延误点：创始人协议未同步、IP 归属未闭环。

## A2（触发场景）
- 触发：`投资人要尽调` / `我在做种子轮` / `律师要求 DD 材料`

## E（执行步骤）
1. 识别轮次（种子 / 天使 / A 轮 / Pre-A）。
2. 生成九大文件簇清单：治理、人员、财税、知识产权、合同、融资、产品、合规、诉讼、数据。
3. 生成缺口检测：缺哪类文件 -> 负责人的默认建议。
4. 输出“14 天 DD 冲刺表”：每天优先处理的文件。

## B（边界）
- 不替代律师审阅的法律条款解释。
- 不执行估值计算与交易条款谈判。
- 出现高风险争议/担保/优先清算条款时，需转交律师。
