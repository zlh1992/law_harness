# Desktop Law Harness：安装与启动

## A. 当前已验证链路（Codex 订阅桥接）

这条链路复用已经登录 ChatGPT 的 Codex CLI，不读取或复制 `~/.codex/auth.json`：

```text
DeepSeek Harness :3080
  -> 本地 OpenAI 兼容代理 :4010
  -> codex exec（ChatGPT 订阅登录）
  -> GPT-5.6 Sol
```

在 Mac 上执行：

```bash
cd /Users/zlh1992_home/Desktop/law_harness
./install/install-mac.sh
./bin/start-proxy.sh
```

另开一个终端启动界面：

```bash
cd /Users/zlh1992_home/Desktop/law_harness
./bin/start-harness.sh "$PWD"
```

打开 [http://127.0.0.1:3080](http://127.0.0.1:3080)。检查代理：

```bash
./bin/healthcheck.sh
```

### 法务技能、记忆与溯源

首次在一台新机器启动前，再执行：

```bash
./install/install-law-integrations.sh
./install/install-internet-tools.sh
```

`start-harness.sh` 会将已审阅的 `law-assistant` 预设同步到 Harness 运行目录，自动加载项目内 8 个 `.dsh/skills/`，启动只读法务 LLM Wiki、本地 SQLite Memory、Semantica、混合互联网检索、Free Search 正文读取与 Agent Reach 公共平台 MCP，并装配 Session Files Cordis 插件。`install-internet-tools.sh` 从固定 GitHub tag 下载 SHA-256 校验的源码：Free Search `v0.9.2` 与 Agent Reach `v1.5.0`，所有进程均运行在本 Mac 的隔离虚拟环境中；它不使用上游的全局安装器。联网发现按 Free Search 50% / Tavily 30% / Exa 10% / SerpAPI 10% 路由，失败依序兜底 Tavily、Free Search（最多三次）。Memory 与 Semantica 状态分别写入 `.data/memory/` 与 `.data/semantica/`。`./bin/healthcheck.sh` 会显示当前桥接模型，预期为 `gpt-5.6-sol`。

本地界面的“文件”按钮要求粘贴本机绝对路径，只登记路径、不复制文件。公网界面的同一按钮提供文件选择器，文档经认证网关保存到 `workspaces/session-files/<sessionId>/uploads/`。支持文本、PDF、DOC/DOCX、RTF/ODT、XLSX 与 PPTX；图片继续使用 Harness 原生图片附件。Agent 只能读取当前会话登记的随机 `file_id`。

### 公网访问（受口令保护）

```bash
./bin/start-public.sh
```

该命令启动代理、Harness、本机登录网关，并优先使用项目内 `.tools/cloudflared` 创建 Cloudflare Quick Tunnel；缺少该工具时才回退到 LocalTunnel。网关只监听 `127.0.0.1:4180`，Harness 与代理仍只监听回环地址。访问者必须输入 `.env` 的 `PUBLIC_ACCESS_PASSWORD`；请勿将其与 `LAW_PROXY_TOKEN` 复用。`PUBLIC_WORKSPACE_ID` 已锁定预注册的“法务助手”工作区，公网请求不能选择标准 Agent 或传入任意 `cwd`。服务运行时保持启动终端开启，按 `Ctrl-C` 关闭。Quick Tunnel 仅适合测试和演示；生产部署应改为绑定自有域名的命名隧道。

固定域名模式使用 Cloudflare remotely-managed named tunnel。在 Cloudflare 为隧道添加 Published application，把 `law.example.com`（替换为自己的域名）指向 `http://localhost:4180`；然后运行 `./bin/save-cloudflare-tunnel-token.sh`，在隐藏输入提示中粘贴 Add a replica 页面提供的 token。脚本将其保存为 `.data/cloudflare-tunnel.token` 并设置权限 `600`。不要把 token 直接写进 `.env` 或启动参数。配置：

```dotenv
PUBLIC_TUNNEL_MODE=named
PUBLIC_URL=https://law.example.com
PUBLIC_TUNNEL_TOKEN_FILE=.data/cloudflare-tunnel.token
```

仍然执行 `./bin/start-public.sh`。启动脚本通过 `--token-file` 连接命名隧道并检查固定地址的 `/healthz`。此方式只需允许本机向 Cloudflare 出站连接，不需要开放公网入站端口；登录口令、限速、受限工作区和安全 Cookie 均继续由 `gateway/public-gateway.mjs` 提供。

没有自有域名时，可以在已安装并登录 Tailscale 的 Mac 上设置 `PUBLIC_TUNNEL_MODE=tailscale`。同一个启动脚本会用 Tailscale Funnel 将稳定的 `*.ts.net` HTTPS 地址反向代理到 `127.0.0.1:4180`，并继续使用项目登录口令；不再创建随机 Quick Tunnel 地址。

## B. DS4 本地模型链路（目标模式）

DS4 是 DeepSeek-V4-Flash 专用本地 Metal 引擎。128GB Mac 使用 Q2 imatrix；DS4 只绑定 `127.0.0.1:8000`。安装与启动：

```bash
./install/install-ds4-mac.sh
./ds4/start-ds4.sh
```

然后仍需在 DS4 前增加一个真正的 TLS/Bearer 网关，向局域网暴露 `:4011`；不要直接把 DS4 监听到 `0.0.0.0`。Harness 使用 `config/dsh-settings-ds4.yaml`，并设置 `DS4_GATEWAY_TOKEN`。

## C. Windows 工作台

Windows 可以只运行 Harness、LLM Wiki、Local Memory 和 MiroFlow，把模型请求发到 Mac。PowerShell 执行：

```powershell
.\install\install-windows.ps1 -MacBaseUrl "http://192.168.1.50:4010/v1"
$env:DSH_PROXY_TOKEN = "从 Mac .env 的 LAW_PROXY_TOKEN 读取的 Token"
dsh web
```

正式局域网使用时，把 `MacBaseUrl` 替换为 TLS 网关地址，例如 `https://mac-llm.local:4011/v1`，并安装自签名 CA 或使用受信任证书。
