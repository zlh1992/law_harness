# Desktop Law Harness：安装与启动

## A. 当前链路（本机 DS4F OpenAI 兼容 API）

Harness 直接使用 OpenAI Chat Completions 格式调用本机 DS4F：

```text
DeepSeek Harness :3080
  -> http://127.0.0.1:8000/v1/chat/completions
  -> deepseek-v4-flash
```

在 Mac 上执行：

```bash
cd /Users/zlh1992_home/Desktop/law_harness
./install/install-mac.sh
npm start -- "$PWD"
```

打开 [http://127.0.0.1:3080](http://127.0.0.1:3080)。检查服务和模型目录：

```bash
./bin/healthcheck.sh
```

### 法务技能、记忆与溯源

首次在一台新机器启动前，再执行：

```bash
./install/install-law-integrations.sh
./install/install-internet-tools.sh
```

`start-harness.sh` 会将已审阅的 `law-assistant` 预设同步到 Harness 运行目录，自动加载项目内 8 个 `.dsh/skills/`，启动受控法务 LLM Wiki、本地 SQLite Memory、Semantica、混合互联网检索、Free Search 正文读取与 Agent Reach 公共平台 MCP，并装配 Session Files Cordis 插件。Wiki 概念 CRUD 经过原子写入、版本检查和 OKF 校验；聊天记录持久化到 `$DSH_HOME/sessions`。模型请求直接发送到 `127.0.0.1:8000`；`./bin/healthcheck.sh` 会验证 Harness 和 DS4F 模型目录。

本地界面的“文件”按钮要求粘贴本机绝对路径，只登记路径、不复制文件。公网界面的同一按钮提供文件选择器，文档经认证网关保存到 `workspaces/session-files/<sessionId>/uploads/`。支持文本、PDF、DOC/DOCX、RTF/ODT、XLSX 与 PPTX；图片继续使用 Harness 原生图片附件。Agent 只能读取当前会话登记的随机 `file_id`。

### 公网访问（受口令保护）

当前构建只开放本机 `127.0.0.1:3080`，`./bin/start-public.sh` 已禁用，不会创建公网隧道。

## B. DS4F 服务

DS4 是 DeepSeek-V4-Flash 专用本地 Metal 引擎。128GB Mac 使用 Q2 imatrix；DS4 只绑定 `127.0.0.1:8000`。安装与启动：

```bash
./install/install-ds4-mac.sh
./ds4/start-ds4.sh
```

当前 Harness 与 DS4F 在同一台 Mac 上运行，二者都只监听 `127.0.0.1`。`/health` 未实现，以 `/v1/models` 作为就绪检查。默认使用 `danger-full-access`（免审批）和 `high` 推理；Think Max 必须选择精确值 `max`。需要收紧权限时设置 `DSH_PERMISSION_MODE=workspace-write` 或 `read-only`。

## C. Windows 工作台

Windows 只有在同机运行兼容的 DS4F 服务时才能使用这份固定回环配置。PowerShell 执行：

```powershell
.\install\install-windows.ps1
dsh web
```
