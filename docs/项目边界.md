# 项目边界

## 当前模式：本机 DS4F 直连

Harness 的 `deepseek` 路由被覆盖为以 OpenAI Chat Completions 格式直连 `http://127.0.0.1:8000/v1`，固定模型为 `deepseek-v4-flash`。不存在模型代理或云端模型备用路由。

当前法务预设只启用了项目级技能、Skill 工具、只读法务 Wiki MCP、本地记忆 MCP、Semantica MCP、会话级文件读取工具，以及受限的互联网 MCP；没有为该预设开启 Shell、通用文件系统、文件写入、浏览器、子代理或工作流工具。Wiki MCP 运行在 `knowledge/legal_okf/` 的 OKF v0.2 只读包上，提供概念检索、资源、校验和审计上下文；任何编辑、批准或发布仍须走独立受控流程。互联网发现只能经过加权 `internet_research` 路由（Free Search 50% / Tavily 30% / Exa 10% / SerpAPI 10%，失败时 Tavily、Free Search 两层兜底且最多三次）。Free Search 只允许读取已经发现的公共 URL/缓存，并阻止本机、私网和带凭据 URL；Agent Reach 只提供匿名、公开、只读的网页、YouTube、Bilibili、V2EX 和 RSS 操作，不提供 Cookie、登录态、下载、私信、写入或通用 Shell。会话文件工具从执行中的 Agent 取得真实 Session ID，只能解析该 Session 已登记的随机 `file_id`。Wiki MCP 只能读取本地知识根目录，不能替代法规时效性核验或律师判断。

## 网络边界

`bin/start-public.sh` 已禁用。Harness 只监听 `127.0.0.1:3080`，DS4F 只监听 `127.0.0.1:8000`。

公网文件上传由网关直接接收，默认单文件 25 MB、每会话 250 MB，使用扩展名白名单、随机落盘名、`0600` 文件权限和 Session 目录隔离。公网路由明确禁止 `/api/session-files/local-reference`，因此远端浏览器不能把任意 Mac 路径登记成可读文件。文件不会被执行，也不会被插件自动删除；生产部署必须另行定义保留期和清理流程。

模型请求不会离开本机，但联网检索 MCP 仍会把搜索词发送给其配置的公共搜索服务。高敏感材料仍需遵循组织的数据分类、最小权限和审计策略。

## DS4 模式：本地推理节点

`ds4/start-ds4.sh` 只负责启动 DS4 Server。DS4 本身不是安全网关，也不提供完整 API 鉴权；正式 LAN 部署必须另加：

- TLS
- 强 Bearer Token
- Windows IP 白名单
- 请求大小、超时和并发限制
- SSE 透传与健康检查
- 不记录合同正文的元数据审计

当前只有这一条本地模型链路；没有云端模型回退。
