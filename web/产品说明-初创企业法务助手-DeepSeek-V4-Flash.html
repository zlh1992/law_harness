LOCAL KNOWLEDGE GUIDE

本地知识库使用说明

本地知识库用于查询已收录资料、登记候选来源、更新条目、归档旧版本和检查来源覆盖。使用时应明确法域、时间点与资料范围；新增或修改内容先生成变更预览，经法务确认后再写入，回答不得补造本地库中不存在的依据。

查询 / 核验

返回条目、来源、法域、日期和覆盖不足，不补造引用。

查询知识库：上海初创公司首位销售入职前，需要准备哪些用工材料？列出来源和待核验项。

新增候选知识

只进入待审区；必须附来源、发布时间、适用范围和摘要。

新增候选知识：把这份监管文件登记到 compliance/，生成来源卡、影响标签和变更预览；不要直接发布。

更新并保留差异

新旧版本并存，标记生效日期、冲突和受影响 Skill。

更新知识条目：对比现行版本与新文件，输出 diff、失效段落、受影响问答和需重跑的 Skill；等待我确认。

归档 / 删除

默认软归档，不物理抹除来源和历史引用。

归档知识条目：将旧版政策标记为 superseded，保留来源、替代版本、归档原因和引用关系。

蒸馏为 Skill

把稳定事实转成触发条件、输入、步骤、输出和边界。

蒸馏 Skill：把“首聘员工入职检查”转为触发条件 → 必问事实 → 7/30天动作 → 升级律师条件，并绑定来源。

批量质量检查

找无来源、过期、冲突、孤立和无法追踪到原文的条目。

知识库体检：列出超过90天未复核、缺来源日期、存在冲突或未绑定 Skill 的条目，按高/中/低排序。
推荐治理门槛：模型只能创建草案和差异；法务审核人批准后才发布；每次变更记录操作者、时间、来源、影响范围和回滚点。网络摘要只能进入待审区，不能直接升级为权威知识。
LOCAL MEMORY

Memory 记住工作方式，不代替知识库

当前运行的是自建 `law-local-memory 1.0.0`：通过 DeepSeek Harness MCP Client 连接本地 SQLite。无云 API、无自动全量归档、无向量模型；只有用户明确发出“记住 / 回忆 / 查看 / 忘记”时才调用。

SINGLE TENANT · LOCAL ONLY

适合记住什么？

写作偏好、已确认的脱敏事项事实、项目别名、行动计划和下一次要继续的节点。

  • 不保存身份证号、完整合同或商业秘密
  • 不把模型推断当成已确认事实
  • 客户/事项之间不得交叉召回
  • 每条记忆可查、可纠正、可删除
记住请记住：以后法务风险清单按 7/30/90 天展示，标签“输出偏好”。
回忆请回忆：我们此前确认的风险清单展示偏好是什么？
查看近期记忆请列出最近 5 条记忆，只显示 ID、标签和脱敏摘要。
遗忘请忘记 memory-xxxxxxxxxxxxxxxx，并确认是否已删除。

客户如何看 Semantica

复制答复末尾的 trace_id，要求助手：“回看决策溯源 lawtrace-…”。返回问题、答案、Skill、来源、不确定性、置信度、答案哈希和 integrity_verified。置信度是生成时的证据充足度标记，不是胜诉概率。

客户如何看 Harness 轨迹

打开对应会话，在消息流中展开工具行或右侧“详情”：可按时间看到 skill(workforce) → skill(foundation) → skill(wiki) → skill(matcher) → record_legal_answer → 最终答案。

优势

复核人能快速定位“哪一步用了什么依据”；知识更新后可检索受影响 trace；答案被改写时能通过哈希发现；培训和质控可直接复盘工具路径。

不能证明什么

完整性校验不能证明法律结论必然正确，也不能替代原文、法域和时效核验。错误来源被完整记录，仍然是错误来源，因此必须有人复核。

客户数据提示：公网演示只使用脱敏材料。完整合同、身份证号、商业秘密、未公开融资条件及个人敏感信息应在完成身份、网络、权限、日志和数据分类加固的专有部署中处理。
